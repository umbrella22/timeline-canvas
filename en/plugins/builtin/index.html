    Built-in Plugins#

    Timeline Canvas includes a set of built-in plugins. You can load them via timeline.usePlugin().

    #📋 Plugin Directory

    #Essentials

    • ContextMenuPlugin - context menu plugin
    • EventTooltipPlugin - event tooltip plugin
    • LightThemePlugin - light theme plugin
    • DarkThemePlugin - dark theme plugin
    • PerformanceOverlayPlugin - performance overlay plugin

    #Media

    • EventMediaPlugin - event media plugin

    #Utilities

    • MutexGuardPlugin - event mutex plugin
