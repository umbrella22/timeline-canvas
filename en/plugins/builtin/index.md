Timeline Canvas includes a set of built-in plugins. You can load them via `timeline.usePlugin()`.

## 📋 Plugin Directory

* [ContextMenuPlugin](/timeline-canvas/en/plugins/builtin/context-menu.md) - context menu plugin
* [EventTooltipPlugin](/timeline-canvas/en/plugins/builtin/event-tooltip.md) - event tooltip plugin
* [LightThemePlugin](/timeline-canvas/en/plugins/builtin/light-theme.md) - light theme plugin
* [DarkThemePlugin](/timeline-canvas/en/plugins/builtin/dark-theme.md) - dark theme plugin
* [PerformanceOverlayPlugin](/timeline-canvas/en/plugins/builtin/performance-overlay.md) - performance overlay plugin
