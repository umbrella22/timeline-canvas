    高性能 Canvas 时间轴组件

    轻量级、插件化、高性能的时间数据可视化方案

    快速开始在线演示

    🚀 高性能渲染

    基于 HTML5 Canvas，轻松处理成千上万个事件，保持 60FPS 流畅体验。

    🔌 插件化架构

    核心功能与扩展分离，内置主题、右键菜单、性能监控等丰富插件。

    🎨 深度定制

    支持自定义主题、事件样式、轨道布局，满足各种 UI 设计需求。

    🖱️ 丰富交互

    支持缩放、拖拽移动、调整大小、框选、吸附等自然流畅的交互操作。

    🖼️ 多媒体支持

    原生支持在时间轴上渲染波形图、关键帧图片等富媒体内容。

    📦 TypeScript

    完全使用 TypeScript 编写，提供完整的类型定义，开发体验极佳。
